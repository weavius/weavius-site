# Weavius — V3

Version 3 du site Weavius : direction artistique éditoriale et immersive, interface entièrement francophone, responsive et sans framework.

## Important : votre logo

Le site utilise volontairement :

`assets/logo.png`

Placez votre véritable fichier `logo.png` dans ce dossier. Le même logo est utilisé dans la navigation, le pied de page et les pages TenWords / Novaia.

## Lancer le site

Aucune installation n'est nécessaire.

- Ouvrir `index.html` dans un navigateur.
- Ou utiliser Live Server dans VS Code.

## Structure

- `index.html` — accueil
- `style.css` — design complet
- `script.js` — interactions et animations
- `apps/tenwords.html` — page TenWords
- `apps/novaia.html` — page Novaia
- `assets/logo.png` — logo Weavius à fournir
- `assets/icons/favicon.svg` — favicon

## Publication

Compatible avec GitHub Pages, Cloudflare Pages ou tout hébergement statique.

Avant publication, remplacer `hello@weavius.com` si nécessaire.
